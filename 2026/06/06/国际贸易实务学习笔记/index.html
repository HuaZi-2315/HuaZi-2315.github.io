国际贸易实务是什么

国际贸易实务是研究国际货物买卖的有关理论和实际业务操作的一门学科。它以进出口贸易合同为中心，围绕合同条款、交易磋商、合同履行以及各种国际贸易方式，系统介绍从事国际商品交换需要掌握的基础知识、基本技能和操作规范。
简单来说，就是学习如何与国外客户谈生意、签合同、发货、收款，并处理好运输、保险、报关、检验、争议解决等一整套流程。对于国际经济与贸易、商务英语、物流管理等专业的同学来说，这门课既是核心专业课，也是外贸从业资格考试（如外贸单证员、外贸业务员、报关员）的重要基础。

本文根据黎孝先、王健主编的《国际贸易实务》（第七版，对外经济贸易大学出版社）整理学习笔记。

2.适合任何运输方式（7种）

EXW（工厂交货）(insert named place of delivery)Incotermsr ®2010

  • 卖方责任最小，买方上门提货。

双方的义务：
A2卖方协助
B2买方自负风险和费用，取得出口许可或出口相关货物所需的其他官方授权

A3卖方无订立运输合同的义务，无订立保险合同的义务
B3买方也无订立运输，保险合同的义务

A4交货
卖方必须在指定的交付地点或该地点内的约定点（如果有的话）以将未置于任何运输车辆上的货物交给买方处置的方式交货

B6费用买方必须支付任何装运前强制检验费用，包括出口国有关机构强制进行的检验；买方必须支付由于其未收取已处于可由其处置状态货物而产生的额外费用。

FCA（货交承运人）(insert named place of delivery)Incotermsr ®2010

  • 卖方办出口清关，交承运人。

双方义务：
A2卖方自负风险和费用，取得出口许可证或其他官方批准证件，并且办理货物出口所需要的海关手续。
B2买方自负风险和费用，取得进口许可证或其他官方批准证件，并且办理货物出口所需要的海关手续。。

A3，B3
双方均无订立运输合同和保险合同的义务。

A4交货
将货物交付给买方指定的承运人或其他人
以下情况，交货完成：
a）若指定的地点是卖方所在地(premises)，则当货物被装上买方提供的运输工具时；
b）在任何其他情况下，则当货物在卖方的运输工具上可供卸载，并可由承运人或买方指定的其他人处置时。

风险转移
如果
a）买方未按照通知其所指定的承运人或其他人，或发出通知；
b）买方指定的承运人或其他人未在约定的时间接管货物；
则买方承担货物灭失或损坏的一切风险
以该货物已清楚确定为合同下之货物者为限

CPT（运费付至）（insert named place of destination）Incotermsr ®2010

  • 卖方付运费至目的地。
  • 风险转移问题（货交承运人）
  • 通关手续问题（同FCA）
  • 运输，保险合同：卖方有义务订立运输合同。
  • 主要费用划分：卖方多增加运费（装卸费可包含在运费中，具体写明合同中）。

CIP（运费和保险费付至）（carriage and insurance paid to）

  • 卖方再加付保险费。
  • 风险转移问题（货交承运人）
  • 通关手续问题（同FCA）
  • 运输，保险合同：卖方有义务订立运输合同。
  • 主要费用划分：卖方多增加运费（装卸费可包含在运费中，具体写明合同中）,和保险费（代办性质）。

    DAT（运输终端交货）(delivered at terminal)

    运输终端指任何地点，例如码头、仓库、集装箱堆场或公路、铁路、空运货站，而不论该地是否有遮盖。
  • 风险转移问题：交货即风险转移，指定的港口或目的地运输终端，将从抵达的运输工具上卸下的货物交给买方处置
  • 通关手续问题：买卖双方各自负责进口和出口相关手续
  • 运输合同和保险合同问题：卖方负责订立运输合同，无义务订立保险合同
  • 主要费用的划分：卖方交货之前，买方交货之后

    DAP（目的地交货）(delivered at place)

  • 风险转移问题：交货即风险转移，处于已抵达的运输工具上的，且已做好卸货准备的货物交给买方处置。
  • 通关手续问题：买卖双方各自负责进口和出口相关手续。
  • 运输合同和保险合同问题：卖方负责订立运输合同，无义务订立保险合同
  • 主要费用的划分：卖方交货之前，买方交货之后

DAT和DAP的区别主要为交货地点不同

DDP（完税后交货）(delivered duty paid)

  • 卖方责任最大，送货上门并办进口清关。
  • 风险转移问题：交货即风险转移，处于已抵达的运输工具上的，且已做好卸货准备的货物交给买方处置。
  • 通关手续问题：卖方必须自负风险和费用，取得进出口许可证或其他官方授权，办理货物出口、从他国过境运输和进出口所需的一切海关手续。
  • 运输合同和保险合同问题：卖方负责订立运输合同，无义务订立保险合同
  • 主要费用的划分：卖方交货之前并包括进出口费用，买方交货之后

3.适用于水上运输方式的贸易术语（4种）

FAS（船边交货）(insert named port of shipment)Incotermsr ®2010

  • 买方派船，卖方送到船边。
  • 风险转移问题：船边转移
  • 通关手续问题：买卖双方各自负责进口和出口相关手续
  • 运输合同和保险合同问题：卖方无订立运输合同的义务，无义务订立保险合同
  • 主要费用的划分：卖方交货之前，买方交货之后

    FOB（船上交货）(insert named port of shipment)Incotermsr ®2010

  • 卖方装船，越过船舷后风险归买方。
  • 风险转移问题：将货物置于买方指定的船上，或以取得已在船上交付的货物的方式交货。
  • 通关手续问题：买卖双方各自负责进口和出口相关手续
  • 运输合同和保险合同问题：卖方无订立运输合同的义务，无义务订立保险合同
  • 主要费用的划分：卖方交货之前，买方交货之后

    CFR（成本加运费）(insert named port of destination)Incotermsr ®2010

  • 卖方租船付运费，风险同FOB。
  • 风险转移问题：将货物置于买方指定的船上，或以取得已在船上交付的货物的方式交货。
  • 通关手续问题：买卖双方各自负责进口和出口相关手续
  • 运输合同和保险合同问题：卖方订立运输合同的义务，无义务订立保险合同
  • 主要费用的划分：卖方交货之前，买方交货之后

    CIF（成本、保险费加运费）(insert named port of destination)Incotermsr ®2010

  • 卖方多付保险费，象征性交货。
  • 风险转移问题：将货物置于买方指定的船上，或以取得已在船上交付的货物的方式交货。
  • 通关手续问题：买卖双方各自负责进口和出口相关手续
  • 运输合同和保险合同问题：卖方订立运输合同的义务，义务订立保险合同
  • 主要费用的划分：卖方交货之前，买方交货之后

重点术语对比：CIF、CFR、FOB为象征性交货（凭单交货），DAT、DAP、DPP是实际性交货（需要到目的地，买方手里）

二、国际货物买卖合同

1.合同的主体和标的

  • 合同当事人（主体）
    以自己的名义订立与滤芯合同，并享有一定权利和承担约定义务的人

注意事项：
必须具备缔约能力
名称必须表述清楚
地址应该正确详细

  • 成交商品的名称
    对交易标的物进行的描述，构成商品说明的一个主要组成部分。品名在一定程度上体现了商品的自然属性，用途以及主要的性能特征，最好采用国际通用的名称

注意事项：
根据需要与可能约定成交商品的名称
合理描述成交的商品
正确使用成交商品的名称
品名条款的内容应当清楚、明确、具体

  • 进出口商品的质量
    商品的内在素质和外观形态的综合表现
    直接影响商品的价值和使用价值

  • 进出口商品的质量，合同的相关规定：
    《联合国国际货物销售合同公约》规定：卖方交货必须符合约定的质量，如卖方交货不符约定的品质条件，买方有权要求损害赔偿，也可要求修理或交付替代货物，甚至拒收货物和撤销合同。
    （1）卖方交付的货物必须与合同所规定的数量、质量和规格相符，并须按照合同所规定的方式装箱或包装。
    （2）除双方当事人业已另有协议外，货物除非符合以下规定，否则即为与合同不符：（a）货物适用于同一规格通常使用的目的；（b）货物适用于订立合同时曾明示或默示地通知卖方的任何特定目的，除非情况表明买方并不依赖卖方的技能和判断力。或者这种依赖对他是不合理的；（c）货物的质量与卖方向买方提供的货物样品或样式相同；（d）货物按照同类货物通用的方式装箱或包装，如果没有此种通用方式，则按照足以保全和保护货物的方式装箱或包装。

  • 表示品质的方法
    （1）凭规格买卖
    （2）凭等级买卖
    （3）凭标准买卖
    （4）凭说明书和图样买卖
    （5）凭商标或品牌买卖
    （6）凭产地名称买卖

    注意事项：
    正确运用各种表示品质的方法
    防止约定的品质条件出现偏高或偏低
    合理选定影响品质的质量指标
    应注意进口国的有关法令规定
    要注意各项质量指标间的内在联系和相互管子
    力求约定的品质条款明确、具体

2. 国际货物运输

国际货物运输保险的基本概念

  • 保险
    保险是一种补偿性契约关系。一方面被保险人必须向保险人提供一定的对价，即按合同的规定缴纳保险费；另一方面保险人应对被保险人将来可能遭受的某些损失依合同规定承担经济赔偿责任。
  • 保险标的
    保险所要保障的目标或对象，是保险事故发生的承受体。
    可以是有形物，也可以是无形的利益、责任和信用。
  • 保险合同的标的
    投保人或被保险人在保险合同中要求获得保障的不是特定的标的，而是在特定标的中所具有的经济利益：可保利益。是指投保人或被保险人对于保险标的因有利害关系而产生的为法律所承认，可以投保的经济利益。
  • 保险价值
    被保险人与保险人共同约定记载于保险合同中的保险标的价值，不一定等于保险标的实际价值。
  • 保险金额
    被保险人对保险标的的实际投保金额，是保险人计算保费的依据，也是保险人承担损失赔偿责任的最高限额
  • 保险价值
    被保险人与保险人共同约定记载于保险合同中的保险标的价值，不一定等于保险标的实际价值。
  • 保险金额
    被保险人对保险标的的实际投保金额，是保险人计算保费的依据，也是保险人承担损失赔偿责任的最高金额。足额保险；不足额保险；超额保险
  • 保险费
    保险人因承担特定的赔偿或给付责任而向投保人或被保险人收录的费用。

    海运货物保险承保的风险

  • 海上风险
    不包括所有发生在海上的风险，也不局限于航海中发生的风险
  • 外来风险
    外来风险是指海上风险以外由于其他各种外来的原因所造成的风险。

    海运货物保险保障的损失

    全部损失
    • 实际全损：
      保险标的完全灭失；保险标的丧失了原有用途；保险标的的所有权已经不可挽回的丧失了。船舶失踪达到一定期限（中国船舶保险条款规定，以该船预计到达目的港日期为准，超过两个月没有音讯）
      保险公司赔偿实际全损后，以被保险人的名义进行任何法律活动的权力就自动地转移给了保险人。往往签署一个代位追偿证书。
  • 推定全损：
    实际全损已经不可避免；为避免发生实际全损所需支付的费用与继续将货物运抵目的地的费用之和，将超过保险价值，就够成推定全损。
    被保险人有两个选择
    一是按照推定全损向保险人索赔全部损失赔偿。但被保险人必须向保险人发出委付通知，即向保险人声明愿意将保险标的的一切权益、包括财产权及一切由此而产生的权利与义务转让给保险人，而要求保险人按全损给予赔偿的一种行为。保险人可以接受或拒绝接受委付，但仍按全损赔
    二是被保险人保留标的，而向保险人要求部分损失的赔偿，无需发出委付通知。
  • 共同海损：
    在海洋运输过程中，船舶、货物或其他财产遭遇共同危险，为了解除共同危险，有意采取合理的救难措施，所直接造成的特殊牺牲和支付的特殊费用，称为共同海损。共同海损牺牲；共同海损费用；共同海损分摊。
  • 单独海损：
    仅涉及单方面的利益的损失

    海运货物保险保障的费用

  • 施救费用
    被保险的货物在遭受承保责任范围内的灾害事故时，被保险人或其代理人、雇员和受让人，为了避免或减少损失而采取各种抢救、保护措施所产生的合理费用。

  • 救助费用
    救助报酬：由遇难船舶或其载货无关的第三者根据契约或海上法律对遇难船舶、货物或其他财产进行救助而获取的报酬
    救助费用：在海上保险中，被保险人因被救助而支付给救助人的报酬被称为救助费用
    三个条件：
    不能自救
    第三方
    有实际效果

  • 其他费用：中途港或避难港，卸货、存仓和运送货物，检验、查勘、公证、理算和拍卖

我国海运货物保险的险别

✓平安险
□货物在运输途中由于恶劣气候、雷电、海啸、地震、洪水自然灾害造成整批货物的全部损失或推定全损。
□由于运输工具遭受搁浅、触礁、沉没、互撞、与流冰或其他物体碰撞以及失火、爆炸意外事故造成货物的全部或部分损失。
□在运输工具已经发生搁浅、触礁、沉没、焚毁意外事故的情况下，货物在此前后又在海上遭受恶劣气候、雷电、海啸等自然灾害所造成的部分损失。
□在装卸或转运时由于一件或数件整件货物落海造成的全部或部分损失。
□被保险人对遭受承保责任内危险的货物采取抢救、防止或减少货损的措施而支付的合理费用，但以不超过该批被救货物的保险金额为限。
□运输工具遭遇海难后，在避难港由于卸货所引起的损失以及在中途港、避难港由于卸货、存仓以及运送货物所产生的特别费用。
□共同海损的牺牲、分摊和救助费用。
□运输契约订有 “船舶互撞责任” 条款，根据该条款规定应由货方偿还船方的损失
✓水渍险
保险公司除担负平安险的各项责任外，还对被保险货物由于恶劣气候、雷电、海啸、地震、洪水等自然灾害所造成的部分损失负赔偿责任
✓一切险
保险公司除担负水渍险的各项责任外，还对被保险货物在运输途中由于一般外来原因而遭受的全部或部分损失负赔偿责任

附加险别
✓ 一般附加险
偷窃提货不着险、淡水雨淋险、短量险、混杂沾污险、渗漏险、碰损和破碎险、串味险、受潮受热险、钩损险、包装破裂险、锈损险
✓ 特殊附加险

  • 战争险
    □ 直接由于战争、类似战争行为和敌对行为、武装冲突或海盗行为所致的损失
    □ 由于上款引起的捕获、拘留、扣留、禁制、扣押所造成的损失
    □ 各种常规武器，包括水雷、鱼雷、炸弹所致的损失
    □ 本条款责任范围引起的共同海损的牺牲、分摊和救助费用
    • 罢工险
      本保险对被保险货物由于罢工者，被迫停工工人或参加工潮、暴动、民动、民众斗争的人员的行动，或任何人的恶意行为所造成的直接损失和上述行为或行为所一起的共同海损、牺牲、分摊和救助费用负赔偿责任。

仓至仓责任
自被保险货物运离保险单所载明的起运地仓库或储存处所开始，涵盖正常运输里的海上、陆上、内河、驳船运输；
保障终止节点分三类：

  1. 货物送达保险单载明目的地收货人的最后仓库 / 储存处所；
  2. 货物被收货人用于分配、分派或非正常运输的其他储存处所；
  3. 若未抵达上述仓库，以货物在最后卸载港全部卸离海轮后满 60 天为止；
  4. 60 天内货物转运至非保单载明目的地，保障自开始转运时立即终止。

运输方式

班轮运输：

1.固定航线、船期、费率，运费基本结构为基本运费+附加费。
2.船方负责配载装卸、装卸费包括在运费中，不计算滞期费和速遣费
3.船货双方权利与义务以船方签发的提单条款为依据
4.货物的品种，数量比较灵活，货运质量有保证。
运费计算：F=Fb+∑S Fb=基本费率*货运量

租船运输：

1.没有固定的航线、固定的装卸港口和固定的船期，它根据租船人的需要和船东的可能，由双方洽商租船运输条件，并以租船合同形式加以肯定，作为双方权利和义务的依据。
2.没有固定的运价。租船运价受阻船市场供求关系的制约。
3.租船运输一般是整船洽租并以装运货值较低、成交数量较多的大宗货物为主。

集装箱运输

□ 提高装卸效率和加快船舶周转
□ 提高运输质量和减少货损货差
□ 节省各项费用和降低货运成本
□ 简化货运手续和便利货物运输
□ 把传统单一运输变成连贯的成组运输，促进了国际多式联运的发展
✓ 集装箱货物交接方式

  • 整箱交，拆箱接（FCL/LCL）：货主在工厂或仓库把装满货后的整箱交给承运人，在目的地的集装箱货运站或内陆转运站由承运人负责拆箱后，各收货人凭单接货。
  • 拼箱交，整箱接（LCL/FCL）：货主将不足整箱的小票托运货物在集装箱货运站或内陆转运站交给承运人。由承运人分类调整，把同一收货人的货集中拼装成整箱，运到目的地后，承运人以整箱交，收货人以整箱接。

    其他运输方式

    铁路运输（中欧班列）、航空运输、集装箱运输、国际多式联运等。

运输单据

海运提单（B/L）

✓ 定义
《海商法》：是指用以证明海上货物运输合同和货物已经由承运人接收或者装船，以及承运人保证据以交付货物的单证。
✓ 性质

  • 承运人出具的接收货物的收据
    ——已被接管/装船
    ——接管/装船时的数量/件数 ——接管/装船时的表面状况
  • 提单是海上货物运输合同的证明
    ——合同早已成立，签提单是在履行合同
    ——是承运人单方面的行为
  • 提单是承运人据以交付货物的单证，是提货凭证
    ——持有人有提货的权利
    ——承运人有交货的义务
    ✓提单条款
    □ 正面条款
    ①托运人提供并填写部分
    ②承运人填写的部分
    ③提单印就的文字条款：外表状况良好条款；内容不知条款；承认接受条款
    □ 背面条款
    ①定义条款
    ②首要条款
    ③承运人的责任和豁免条款：多数规定以《海牙规则》为准
    ④承运人责任期间
    ⑤包装和标志条款
    ⑥运费和其他费用条款：方式、时间、币种和计算方法
    ⑦自由转船条款
    ⑧托运人错误申报条款
    ⑨承运人赔偿责任限额条款
    ⑩危险品、违禁品条款
    ⑪共同海损条款
    ⑫留置权条款
    ⑬美国条款
    ✓种类
    □ 已装船提单与备运提单
    □ 清洁提单与不清洁提单
    □ 记名提单，不记名提单，提示提单
    □ 过期提单（Stable B/L）、预借提单（Advanced B/L）、倒签提单（Anti-dated B/L）
    预借和倒签提单：提单有效；承运人欺诈，免除承运人享受免责的权利
    □ 直达提单、转船提单与联运提单
    □ 正本提单与副本提单

海运单

✓ 定义
证明海上运输合同和货物由承接人接管或装船，以及承运人保证据以将货物交付给单证所载明的收货人的一种不可流通的单证，因此又称“不可转让海运单”

航空运单

□ 承运人与托运人之间签订的运输契约，也是承运人或其代理人签发的货物收据。
□ 不是物权凭证，不能背书装让；
□ 依签发人的不同可分为主运单（Master Air Waybill）和分运单（House Air Waybill）；
□ 正本一式三份：”Original for the Shipper”应交托运人；”Original for the Issuing Carrier”，由航空公司留存；”Original for the Consignee”，由航空公司随机带交收货人；其余副本则分别注明”For Airport of Destination”等。

多式联运单据

□ 多式联运单据是多式联运合同的证明，也是多式联运经营人收到货物的收据和凭以交付货物的凭证。
□ 根据发货人的要求，它可以作成可转让的，也可以作成不可转让的。
□ 多式联运单据如签发一套一份以上的正本单据，应注明份数，其中一份完成交货后，其余各份正本即失效。
□ 注意和联运提单的区别

国际铁路运输单据

□ 多式联运单据是多式联运合同的证明，也是国际铁路联运的主要运输单据，它是参加联运的发送国铁路与发货人之间订立的运输契约。
□ 铁路承运货物出具的凭证，也是铁路与货主交接货物、核收运杂费和处理索赔与理赔的依据
□ 运单副本于运输合同缔结后交给发货人，是卖方凭以向收货人结算货款的主要证件。

3. 进出口商品的价格

1. 成交价格的掌握
◆ 加强成本核算
✓ 出口总成本与出口成本价格

  • 出口总成本 = 进货成本 + 国内费用 + 出口税
  • 出口成本价格 = 单位成本价格
  • 出口成交价格 = 单位成本价格 + 单位商品的国外费用
    ✓ 出口外汇净收入和出口换汇成本
  • 出口外汇净收入 = 出口外汇总收入 - 劳务费用等
  • 出口换汇成本 = 出口总成本（人民币）/ 出口外汇净收入（外汇）
    ✓ 出口盈亏额与盈亏率
  • 出口盈亏额 = 出口销售人民币 - 出口总成本
  • 出口盈亏率 = 出口盈亏额 / 出口总成本
    ✓ 成品出口创汇率
  • 成品出口创汇率 =（成品出口外汇净收入 - 原料外汇成本）/ 原料外汇成本
    ◆ 价格构成和价格换算
    ✓ 主要贸易术语的价格构成（进货成本，各项费用开支，净利润）
    FOB、CFR、CIF的价格构成
  • FOB价格 = 进货成本价 + 国内费用 + 净利润
  • CFR价格 = 进货成本价 + 国内费用 + 国外运费 + 净利润
  • CIF价格 = 进货成本价 + 国内费用 + 国外运费 + 国外保险费 + 净利润
    FCA、CPT、CIP的价格构成同上（运输方式不同，略有区别）
    ✓ 主要贸易术语的价格换算
  • CIF价格 = FOB价格 + 国外运费 + 国外保险费
  • CIF价格 = FOB价格 + CIF价格 ×（1 + 保险加成率）× 保险费率 + 国外运费
  • CFR价格 = FOB价格 + 国外运费
    ◆ 价格构成和价格换算
    ✓ 主要贸易术语的价格构成（进货成本，各项费用开支，净利润）
    FOB、CFR、CIF的价格构成 ✓
  • FOB价格 = 进货成本价 + 国内费用 + 净利润
  • CFR价格 = 进货成本价 + 国内费用 + 国外运费 + 净利润
  • CIF价格 = 进货成本价 + 国内费用 + 国外运费 + 国外保险费 + 净利润
    FCA、CPT、CIP的价格构成同上（运输方式不同，略有区别）
    ✓ 主要贸易术语的价格换算
  • CIF价格 = FOB价格 + 国外运费 + 国外保险费
  • CIF价格 = FOB价格 + CIF价格 ×（1 + 保险加成率）× 保险费率 + 国外运费
  • CFR价格 = FOB价格 + 国外运费
    在价格调整条款中，通常使用下列公式来调整价格：
    P = P₀ × (A + B × M/M₀ + C × W/W₀)
    式中：
  • P —— 商品交货时的最后价格；
  • P₀ —— 签合同时约定的初步价格；
  • M —— 计算最后价格时引用的有关原料的平均价格或指数；
  • M₀ —— 签合同时引用的有关原料的价格或指数；
  • W —— 计算最后价格时引用的有关工资的平均数或指数；
  • W₀ —— 签合同时引用的工资平均数或指数；
  • A —— 经营管理费用和利润在价格中所占的比重；
  • B —— 原料在价格中所占的比重；
  • C —— 工资在价格中所占的比重；
    A、B、C 所分别代表的比例，在签合同时确定后固定不变。
